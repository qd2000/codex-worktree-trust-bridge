# v0.2.2 development timeline — closed

Status: **COMPLETE**. v0.2.2 was released and deployed on 2026-10-14.

The authoritative final identities, sustained results and fleet state are in

## Timeline

1. The original v0.2.1 investigation confirmed two independent risks: the
   Launcher did not own the runtime lifecycle, and the long-lived PowerShell
   runtime performed broad UIA descendant scans.
2. v0.2.2 introduced atomic Job ownership, an isolated bounded MTA UI worker,
   durable uncertain-action handling, exact status evidence, and bounded
   Git/reconcile execution.
3. Exact-identity backup, stop, install, upgrade, rollback and uninstall were
   implemented and passed an isolated maintenance matrix.
4. The first fleet candidate was revoked after a broad Local root exposed stale
   `.git` markers. Local rolled back automatically and expansion stopped.
5. The replacement classified only Git's exact bounded `not a git repository`
   result as a stale discovery marker; all other Git failures remained critical.
6. A later gray validator run was revoked after it raced a naturally completed
   short-lived Git descendant. The final validator tolerates only an identity
   proven to have exited after the exact process-tree snapshot.
7. Final source commit `668c5e4c09d32267bbf91a59117e22bf3bce4771`
   passed the complete suite and live cadence, was frozen as manifest
   `832cbf8eb7eddf7eb67695102b57d6823e2a1073ce5f1135a7c6ed4063c60dc6`,
   and completed the two-hour representative canary.
8. The exact archive was published as v0.2.2 and deployed sequentially to three
   hosts. All final verifications reported `HEALTHY`; machine-specific policy and
   rollback backups were preserved.
